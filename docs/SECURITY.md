# cccalendar 安全与日志规则

## 密钥

- API Key、刷新令牌和未来的同步凭据只能通过 `ISecretStore` 访问。
- Windows 实现使用 Windows 凭据管理器；普通设置 JSON、SQLite、日志和备份不得保存密钥明文。
- UI 读取密钥后只显示是否已配置和末尾少量字符，不回显完整值。
- 测试使用内存替身和显式假密钥，不读取开发者机器凭据。

## 日志

允许记录：

- 操作名称、内部对象 ID、时间、耗时、数量、结果状态和稳定错误码。
- 外部请求的服务名、模型名、HTTP 状态码和重试次数。

禁止记录：

- Authorization、Cookie 等请求头和完整请求/响应正文。
- API Key、令牌、密码及 Windows 凭据内容。
- AI 提示词全文、日程/待办/记录正文、附件内容和剪贴板内容。
- 用户输入的完整文件路径；需要诊断时只记录文件名或应用数据目录的相对路径。

运行时已知密钥必须先经过 `KnownSecretRedactor` 再进入日志。这是第二道防线，不能替代禁止记录敏感载荷的规则。

## 本地文件

- 普通配置位于用户本地应用数据目录，不与可执行文件放在一起。
- 设置保存使用同目录临时文件并原子替换，避免进程中断留下半个 JSON。
- 日志、数据库、备份和附件目录已加入 `.gitignore`。
- 崩溃报告默认不上传；未来如增加上传功能，必须先展示数据范围并征得用户同意。
