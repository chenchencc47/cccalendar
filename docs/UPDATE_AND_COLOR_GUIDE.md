# 更新与颜色设置操作说明

## 检查更新

### 手动检查

1. 打开 ccCalendar 主窗口。
2. 左侧点击“设置”。
3. 进入“桌面外观”页，滚动到页面下方的“应用更新”区域。
4. 点击“检查更新”。

如果有新版本，会提示远端版本号，同时主窗口右上角显示下载图标；点击下载图标会在默认浏览器中打开 OSS 下载地址，下载完成后运行安装包即可升级。

如果没有新版本，会提示“当前已是最新版本”。

### 更新图标

发现新版本后，主窗口右上角“快速新增”按钮左侧会显示下载图标。图标只在有新版本时出现，不会反复弹窗；点击图标才会打开下载地址。

### 启动自动检查

应用启动完成后会自动检查一次 `version.json`。网络失败时不会影响本地日历、天气或会议室功能。

从 0.3.6 开始的安装包包含更新检查功能。0.3.5 及更早版本需要先手动安装一次新版，之后才能自动检查后续更新。启动自动检查失败时保持静默；在设置页手动点击检查时会提示失败原因。

## 颜色设置

1. 打开“设置”→“桌面外观”。
2. 在“颜色”区域找到要修改的颜色，例如“窗口背景”“主要文字”或“今天背景”。
3. 点击颜色名称右侧的小色块，会弹出调色板。
4. 点击预设颜色立即应用；也可以在调色板底部输入 `#RRGGBB`，再点击“应用”。
5. 颜色修改会立即应用到当前选中的桌面组件目标。

颜色仍然可以直接在旁边的十六进制输入框中编辑，格式必须是 `#RRGGBB`。

## 发布新版本（维护者）

1. 修改 `src/CcCalendar.Desktop/CcCalendar.Desktop.csproj` 和 `installer/cccalendar.iss` 的版本号。
2. 执行 `eng\\publish.cmd` 生成安装包。
3. 使用 `Get-FileHash` 计算安装包 SHA-256。
4. 更新仓库根目录的 `version.json`：版本号、下载地址和 SHA-256 必须对应同一个安装包。
5. 使用 `ossutil cp -f` 上传安装包和 `version.json`。
6. 使用 `Invoke-RestMethod` 和 `Invoke-WebRequest -Method Head` 验证公网地址。

当前生产清单地址：

`https://cccalendar-releases-01.oss-cn-heyuan.aliyuncs.com/releases/version.json`

当前发布版本：`0.6.6`

## 助理输入区

助理输入框采用圆角输入容器：回车发送，Shift+Enter 换行，回形针按钮添加附件，右侧箭头发送。模型返回思考内容时，回复上方会出现可折叠的“思考”区块；没有思考内容时不显示。思考是否产生完全由当前 LLM/API 决定，不需要用户额外点击开关。

### 完整颜色选择

点击颜色方块后，弹层展示完整的色相、明暗和灰阶色板。点击“更多颜色...”会打开独立窗口：

- R、G、B 三个通道均可输入 `0–255`。
- 拖动滑杆或修改数字会实时更新颜色预览。
- 点击“确定”应用，点击“取消”放弃。
