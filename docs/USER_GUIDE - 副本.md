# cccalendar 用户使用手册

适用版本：`0.5.2`

cccalendar 是一个本地优先的 Windows 日历与工作台，包含日历、日程、待办、项目、记录、AI 助理、天气、提醒和团队会议室。

## 1. 安装与启动

1. 下载官方安装包并运行 `cccalendar-x.y.z-win-x64-setup.exe`。
2. 按安装向导完成安装。
3. 从开始菜单或桌面快捷方式启动 cccalendar。

应用数据默认保存在 Windows 用户目录下的 `AppData\Local\cccalendar`，包括本地数据库、应用设置和 AI 对话历史。卸载应用不会自动删除这些数据。

## 2. 主界面

左侧导航包含：

- 今天：查看当天日程、待办和天气。
- 日历：按月或周查看日程。
- 项目：查看项目进度、看板、里程碑和甘特图。
- 待办：管理待办事项和四象限。
- 记录：编辑工作记录并保存版本。
- 助理：使用 AI 查询本地日历数据。
- 统计：查看专注和完成情况。
- 工具：倒计时、番茄钟、世界时钟、截图和剪贴板工具。
- 设置：外观、天气、提醒、AI、更新和团队连接。

顶部搜索框用于搜索项目、日程、待办和记录。它是全局搜索框，不是新增输入框。

## 3. 日历与日程

### 查看日程

在“今天”或“日历”页面选择日期即可查看当天安排。点击日程可以查看详情；需要修改时进入编辑窗口保存。

### 快速新增

点击顶部“快速新增”，选择类型：

- 待办：只需填写标题。
- 项目：填写项目名称。
- 记录：填写记录标题，创建后在“记录”页面编辑正文。
- 日程：填写主题、日期、时间，可选会议室、会议号和重复规则。

待办、项目和记录不会显示会议邀请输入框。只有选择“日程”时才会显示会议邀请区域。

### 腾讯会议邀请

1. 选择类型“日程”。
2. 将完整会议邀请粘贴到“会议邀请”框。
3. 点击“导入”，或在输入框按 `Enter`。
4. 应用会尝试填充主题、会议号、日期、时间和会议室。
5. 点击“创建”保存日程。

“粘贴会议邀请”按钮只负责把剪贴板内容放入输入框，不会自动解析；需要再点击“导入”或按 `Enter`。

腾讯会议邀请支持常见的“会议主题/会议时间/与会地点”格式，也支持“会议名称/会议时间/会议地点”、中文年月日日期以及链接后附带腾讯会议号的格式。

### 重复日程

在“重复”中选择“每周重复”，勾选星期，并设置日期范围。应用会为范围内每个选中的星期创建一条日程。

## 4. 会议室看板与团队共享

日程编辑或快速新增窗口右侧会显示会议室看板。绿色区域表示可用，已预约区域显示会议主题和时间。

- 点击或拖动空闲时间段选择会议室和时间。
- 双击已预约区域查看会议详情。
- 悬停已预约区域可查看主题、会议室、开始和结束时间。

要使用云端共享会议室：

1. 打开“设置”→“团队连接”。
2. 填写管理员提供的 API 地址、工作区 ID，以及开发令牌姓名和口令，或使用 OIDC 登录。

| 字段          | 填写内容                                        |
| ------------- | ----------------------------------------------- |
| 服务端地址    | `http://47.120.6.126:5080/`                     |
| OIDC 授权地址 | 留空                                            |
| OIDC 令牌地址 | 留空                                            |
| 客户端 ID     | 留空                                            |
| 工作区 ID     | 可留空，登录成功后自动回填；也可填当前工作区 ID |
| 开发令牌姓名  | 新成员真实姓名，前后不要加空格                  |
| 开发令牌口令  | cccalendar-team-2026                            |

3. 点击“登录团队”。

4. 登录成功后重新打开快速新增或日程编辑窗口，即可读取共享会议室并提交在线预约。

在线预约发生冲突时，服务器会拒绝重复时段，保留本地日程并提示调整时间。

## 4.1 桌面组件鼠标穿透

桌面日历、日程和待办组件均可通过右键菜单切换“鼠标穿透”。开启后，组件不再拦截下方应用的鼠标点击；关闭鼠标穿透可使用系统托盘菜单顶部的“恢复所有桌面组件鼠标操作”，或按默认全局快捷键 `Ctrl + Alt + Shift + P`。也可在“设置 → 全局快捷键”中修改该快捷键。

## 5. 待办与项目

### 待办

在“待办”页面输入标题即可新增待办。可以标记完成、重新打开，并按四象限或看板查看和移动任务。

### 项目

点击“新增项目”或“创建第一个项目”进入快速新增，选择“项目”并创建。项目页面提供概览、看板、里程碑和甘特图。

删除项目时点击项目详情中的“删除项目”，确认后项目会移入回收站，不再出现在当前项目列表中。

## 6. 记录与版本

“记录”页面左侧上方的输入框标注为“搜索记录”，只用于按标题和正文筛选，不会创建记录。

1. 点击右上角“新增记录”。
2. 在快速新增窗口选择“记录”，填写标题并点击“创建”。
3. 返回“记录”页面后，左侧列表会显示新记录。
4. 选择记录，在右侧编辑正文。
5. 点击“保存版本”。

保存状态会显示在按钮左侧：

- 正在保存...
- 已保存版本
- 内容未变化
- 保存失败

左侧记录条目会显示标题和当前版本数。每次正文发生变化并保存，版本号会递增。

## 7. AI 助理

助理支持查询本地的日程、项目、记录和待办。输入问题后按 `Enter` 或点击发送；`Shift+Enter` 插入换行。

示例：

- “我今天有什么日程？”
- “查找标题包含客户拜访的记录。”
- “查看项目应付流程的进度。”
- “找出本周未完成的待办。”

消息列表支持复制消息内容。滚轮可以连续滚动查看历史消息。AI 对话历史保存在本机，不会因为切换页面而丢失。

当前 AI 助理的写入操作需要切换到“写入（需确认）”并在预览卡片中确认；只读模式不会修改本地数据。

## 8. 工具中心

### 倒计时

打开“工具”→“专注”，在“倒计时”标题下的“时长”输入框中填写分钟数，范围为 1 到 1440 分钟。点击“开始”启动，点击“暂停”暂时停止，点击“重置”恢复到设定时长。

倒计时结束时会显示“倒计时完成”，并通过系统提示音和 Windows 托盘通知提醒。应用主窗口可以隐藏，但应用进程需要保持运行。

### 番茄钟

可以分别设置“专注”和“休息”的分钟数：专注时长范围为 1 到 240 分钟，休息时长范围为 1 到 120 分钟。修改时长后会从新的设定重新开始计时。

专注阶段结束会记录一次专注会话，切换到休息阶段，并通过托盘通知和提示音提醒。

### 健康提醒

“整点报时”和“久坐提醒”属于独立的健康提醒。勾选“久坐提醒”后，在输入框填写间隔分钟数，再点击“已起身，重新计时”可以重新开始久坐计时。

## 9. 天气

天气数据来自 Open-Meteo。应用会根据 Windows 自动定位获取城市，也可以在“设置”→“天气”中关闭自动定位并选择城市。

小时预报中的“雨”“阵雨”“毛毛雨”等文字来自 WMO 天气代码；“降水 xx%”是降水概率，两者不是同一个字段。不同天气应用使用不同数据源，预报可能存在差异。

## 10. 提醒

提醒设置位于“设置”→“提醒”，包括：

- Windows 通知
- 应用内弹窗
- 提示音
- 默认稍后提醒时间
- 勿扰时段
- 全屏时是否抑制提醒

应用内弹窗是主要的可视提醒。Windows 通知仅在关闭应用内弹窗时作为备用，不会与应用内弹窗同时显示；提示音仍可独立开启。

“默认稍后提醒”表示在提醒弹窗中选择“稍后”后，下一次提醒延后的时间，不是会议开始前的提醒时间。可以直接输入 1 到 1440 分钟，例如输入 `45` 表示 45 分钟后再次提醒。

### 会议提前提醒

在快速新增或编辑日程的“会议提前提醒”行中，可以单独为当前会议选择提前分钟数（1 到 1440 分钟）。取消勾选就是不提醒；全天日程不会创建提前提醒。该设置只影响当前会议，不会改变其他日程。会议提醒触发后，仍可在弹窗中选择“稍后”，此时才会使用上面的默认稍后提醒分钟数。

提醒服务在应用运行时后台轮询，并支持错过提醒后的补发。当前设置对已经创建的提醒生效；普通日程是否产生提醒取决于该日程是否带有提醒数据。

## 11. 检查更新

打开“设置”→“应用更新”，点击“检查更新”。如果发现新版本，主窗口顶部会出现蓝色下载图标，悬停可以查看版本号，点击即可下载对应安装包。

当前更新流程是下载新的 Windows 安装包后运行安装，不是静默后台替换。安装前请先关闭正在运行的旧版本。

## 12. ICS 导入与导出

顶部工具按钮提供 ICS 导入和导出：

- 导入 ICS：选择外部日历文件并导入日程。
- 导出 ICS：将本地日历导出为标准 `.ics` 文件，便于备份或导入其他日历软件。

## 13. 常见问题

### 创建后看不到项目、记录或日程

确认在快速新增窗口点击了“创建”，而不是直接关闭窗口。创建成功后切换页面或重新打开页面即可刷新列表。

### 保存版本没有新增版本

只有正文内容发生变化时才会创建新版本。如果提示“内容未变化”，说明当前正文与上一个版本相同。

### 团队会议室为空

检查“设置”→“团队连接”是否已登录，API 地址是否可访问，工作区 ID 是否正确。登录成功后重新打开快速新增窗口。

### 天气与其他软件不同

先确认城市和定位是否正确，再比较数据来源和更新时间。cccalendar 使用 Open-Meteo 预报数据。

### 更新检查失败

确认电脑可以访问 OSS 公网地址，并在“设置”中重新点击“检查更新”。更新检查失败不会影响本地日历、待办和记录使用。

## 14. 数据备份建议

重要数据建议定期使用 ICS 导出备份日程，并备份本地 `AppData\Local\cccalendar` 目录。迁移到另一台电脑前，先退出应用，再复制数据文件。
