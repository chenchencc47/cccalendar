# cccalendar 用户使用手册

适用版本：`0.5.9`

cccalendar 是一个本地优先的 Windows 日历与工作台，包含日历、日程、待办、项目、记录、AI 助理、天气、提醒和团队会议室。个人数据保存在本机；团队会议室目录和在线预约由团队 Server 共享。

## 1. 安装与启动

1. 下载官方安装包并运行 `cccalendar-x.y.z-win-x64-setup.exe`。
2. 按安装向导完成安装。
3. 从开始菜单或桌面快捷方式启动 cccalendar。

应用数据默认保存在 `C:\Users\<用户名>\AppData\Local\cccalendar`，包括本地数据库、应用设置、AI 对话历史和剪贴板历史。卸载或覆盖安装不会自动删除这些数据。

## 2. 主界面

左侧导航包含：

- 今天：查看当天日程、待办和天气。
- 日历：按月、周、日程表或会议室查看日程。
- 项目：查看项目进度、看板、里程碑和甘特图。
- 待办：管理待办事项、四象限、看板和列表。
- 记录：编辑工作记录并保存版本。
- 助理：使用 AI 查询本地数据、生成计划或创建待确认提案。
- 统计：查看专注和完成情况。
- 工具：倒计时、番茄钟、世界时钟、截图、贴屏和剪贴板工具。
- 设置：外观、提醒、AI 模型、应用更新和团队连接。

顶部搜索框用于搜索项目、日程、待办和记录。它是全局搜索框，不是新增输入框。顶部还提供“快速新增”、ICS 导入和导出入口。

## 3. 日历与日程

### 查看日程

在“今天”或“日历”页面选择日期即可查看当天安排。日历支持“月”“周”“日程表”和“会议室”四种视图；点击日程可以查看详情，需要修改时进入编辑窗口保存。

### 快速新增

点击顶部“快速新增”，选择类型：

- 待办：填写标题。
- 项目：填写项目名称。
- 记录：填写记录标题，创建后在“记录”页面编辑正文。
- 日程：填写主题、日期、时间，可选会议室、会议号、会议提前提醒和重复规则。

待办、项目和记录不会显示会议邀请输入框。只有选择“日程”时才会显示邀请、会议室和时间字段。

### 腾讯会议邀请

1. 选择类型“日程”。
2. 将完整会议邀请粘贴到“会议邀请”框，或点击“粘贴会议邀请”。
3. 点击“导入”，或在输入框按 `Enter`；`Shift+Enter` 只换行。
4. 应用会尝试填充主题、会议号、日期、原始分钟、时间和会议室。
5. 确认内容后点击“创建”保存日程。

“粘贴会议邀请”按钮只负责把剪贴板内容放入输入框，不会自动解析。导入成功后，原始邀请文本会随日程保存，便于之后复制完整邀请或会议号和链接。

腾讯会议邀请支持常见的“会议主题/会议时间/与会地点”格式，也支持“会议名称/会议时间/会议地点”、中文年月日日期以及链接后附带腾讯会议号的格式。与会地点会尝试模糊匹配当前可用的会议室；匹配不到时仍可手动选择。

### 重复日程

在“重复”中选择“每周重复”，勾选星期，并设置日期范围。应用会为范围内每个选中的星期创建一条日程。每周重复可以创建多条日程，创建前请确认日期范围和提醒设置。

### 会议提前提醒

定时日程可勾选“会议提前提醒”，设置提前 1 到 1440 分钟提醒。全天日程不会创建提前提醒；该设置只影响当前日程。

## 4. 会议室看板与团队共享

日程编辑、快速新增和“日历 → 会议室”视图会显示会议室时间看板。看板默认展示 `08:00–24:00`，按半小时选择；有预约的房间会稳定排在前面。

- 点击或拖动空闲时间段选择会议室和时间；按住 `Ctrl` 可累加选择。
- 绿色区域表示当前选择为空闲，红色表示选择与已有预约重叠。
- 双击已预约区域查看会议详情；悬停可查看主题、会议室、起止时间、会议号、链接和会议人员。
- 蓝色预约是当前登录用户创建的预约，灰色预约是其他成员创建的预约。
- 双击自己的蓝色预约可以删除云端预约；删除后所有成员的看板都会同步移除，当前电脑上的对应本地日程也会删除。
- 双击他人的灰色预约只能查看详情，可点击“添加到我的日程”建立本地副本，不会再次占用云端会议室。
- 会议详情支持复制完整邀请，或只复制会议号和入会链接。

### 登录团队

当前团队使用阿里云 Server 的开发令牌模式。打开“设置”→“团队连接”，填写管理员提供的服务端地址、姓名和口令；OIDC 地址全部留空时使用开发令牌登录。

| 字段 | 填写内容 |
| --- | --- |
| 服务端地址 | 当前团队为 `http://47.120.6.126:5080/`；也可使用管理员提供的地址 |
| OIDC 授权地址、OIDC 令牌地址、客户端 ID | 开发令牌模式留空 |
| 工作区 ID | 可留空，登录成功后自动回填 |
| 开发令牌姓名 | 本人的真实姓名，前后不要加空格；字符必须与团队登记一致 |
| 开发令牌口令 | 通过团队私下渠道获取，不要写入公开文档或群公告 |

点击“登录团队”。状态显示“已登录”后，重新打开快速新增或日程编辑窗口，即可读取云端会议室目录并提交在线预约。姓名相同的设备会使用同一团队身份；姓名改写或多一个空格会被视为另一名成员。

当前云端开发令牌有效期通常为 7 天。客户端启动时会优先恢复本机保存的令牌，令牌过期后会使用已保存的姓名和口令自动续签；如果续签失败，请在“团队连接”中重新点击“登录团队”。令牌保存在 Windows 凭据管理器，本地日程不受登录状态影响。

### 在线预约与跨电脑刷新

保存带会议室的定时日程时，客户端会先向云端提交预约，再保存本地日程。服务器是最终冲突裁决者；同一房间和重叠时段已被占用时会返回冲突，当前本地日程仍会保存，并提示冲突房间、时间和预约人。请更换会议室或调整时间后重新预约。

已打开的会议室看板会在登录后刷新，并以较低频率自动轮询（约 15 秒），因此另一台电脑新增、删除预约后，当前看板通常会自动更新。云端暂时不可用时，个人日程、待办、项目和记录仍可离线使用。

当前公网服务使用 HTTP 明文连接，仅适用于受信任的团队验收环境；不要在不受信任的网络中复用团队口令。正式长期使用应改用 HTTPS 和 OIDC。

## 4.1 桌面组件鼠标穿透

桌面日历、日程和待办组件均可通过右键菜单切换“鼠标穿透”。开启后，组件不再拦截下方应用的鼠标点击；关闭鼠标穿透可使用系统托盘菜单顶部的“恢复所有桌面组件鼠标操作”，或按默认全局快捷键 `Ctrl + Alt + Shift + P`。也可在“设置 → 全局快捷键”中修改该快捷键。

## 5. 待办与项目

### 待办

在“待办”页面输入标题即可新增待办。可以标记完成、重新打开，并在“四象限”“看板”和“列表”之间切换。拖动任务或使用右键菜单可调整四象限和看板列。

### 项目

点击“新增项目”或“创建第一个项目”进入快速新增，选择“项目”并创建。项目页面提供概览、看板、里程碑和甘特图。

删除项目时点击项目详情中的“删除项目”，确认后项目会移入回收站，不再出现在当前项目列表中。

## 6. 记录与版本

“记录”页面左侧上方的输入框标注为“搜索记录”，只用于按标题和正文筛选，不会创建记录。

1. 点击右上角“新增记录”。
2. 在快速新增窗口选择“记录”，填写标题并点击“创建”。
3. 返回“记录”页面后，左侧列表会显示新记录。
4. 选择记录，在右侧编辑正文。
5. 点击“保存版本”。

保存状态会显示在按钮左侧：

- 正在保存...
- 已保存版本
- 内容未变化
- 保存失败

左侧记录条目会显示标题和当前版本数。每次正文发生变化并保存，版本号会递增。

## 7. AI 助理

助理支持查询本地的日程、项目、记录和待办，也可以生成每日计划、周报草稿和写入提案。输入问题后按 `Enter` 或点击发送；`Shift+Enter` 插入换行。

示例：

- “我今天有什么日程？”
- “查找标题包含客户拜访的记录。”
- “查看项目应付流程的进度。”
- “找出本周未完成的待办。”

助理顶部会显示当前模型、提供商以及“仅本地”或“在线发送”状态。仅本地模式只允许连接本机 Ollama。在线模型发送前请确认数据范围；API Key 保存在 Windows 凭据管理器。

消息列表支持复制消息内容、切换历史会话和新建/删除对话。模型返回思考内容时，回复上方会出现可折叠的“思考”区块。请求失败或取消后可点击“重试上次请求”，发送过程中可点击停止。

可以通过回形针添加 `.txt`、`.md`、`.csv`、`.json` 或 `.ics` 文本附件：最多 5 个，单个不超过 1 MB，合计不超过 2 MB。附件正文只用于当前请求；发送失败时会保留附件以便重试。

当前 AI 助理的写入操作需要切换到“写入（需确认）”并在预览卡片中确认；修改、删除和批量操作也需要确认并记录审计。只读模式不会修改本地数据，已执行的变更可使用“撤销上次操作”（在支持撤销的操作中）。

## 8. 工具中心

“工具”页面分为“时间工具”“专注”“截图与贴屏”“剪贴板”四个页签。

### 倒计时

打开“工具”→“专注”，在“倒计时”标题下的“时长”输入框中填写分钟数，范围为 1 到 1440 分钟。点击“开始”启动，点击“暂停”暂时停止，点击“重置”恢复到设定时长。

倒计时结束时会显示“倒计时完成”，并通过系统提示音和 Windows 托盘通知提醒。应用主窗口可以隐藏，但应用进程需要保持运行。

### 番茄钟

可以分别设置“专注”和“休息”的分钟数：专注时长范围为 1 到 240 分钟，休息时长范围为 1 到 120 分钟。修改时长后会从新的设定重新开始计时。

专注阶段结束会记录一次专注会话，切换到休息阶段，并通过托盘通知和提示音提醒。

### 其他工具

“时间工具”提供时间进度、日期计算和世界时钟；“截图与贴屏”提供区域/窗口截图、标注、OCR、马赛克、长截图、窗口置顶和截图贴屏；“剪贴板”保存文本、图片和文件历史，可搜索和收藏。

### 健康提醒

“整点报时”和“久坐提醒”属于独立的健康提醒。勾选“久坐提醒”后，在输入框填写间隔分钟数，再点击“已起身，重新计时”可以重新开始久坐计时。

## 9. 天气

天气显示在“今天”页面的天气区域，数据来自 Open-Meteo。勾选“自动定位”后，应用会根据 Windows 定位获取城市；定位不可用时，取消勾选并搜索、选择城市即可。也可以点击刷新按钮重新获取天气。

小时预报中的“雨”“阵雨”“毛毛雨”等文字来自 WMO 天气代码；“降水 xx%”是降水概率，两者不是同一个字段。不同天气应用使用不同数据源，预报可能存在差异。

## 10. 提醒

提醒设置位于“设置”→“提醒”，包括：

- Windows 通知
- 应用内弹窗
- 提示音
- 默认稍后提醒时间
- 勿扰时段
- 全屏时是否抑制提醒

应用内弹窗是主要的可视提醒。Windows 通知仅在关闭应用内弹窗时作为备用，不会与应用内弹窗同时显示；提示音仍可独立开启。

“默认稍后提醒”表示在提醒弹窗中选择“稍后”后，下一次提醒延后的时间，不是会议开始前的提醒时间。可以直接输入 1 到 1440 分钟，例如输入 `45` 表示 45 分钟后再次提醒。

提醒服务在应用运行时后台轮询，并支持错过提醒后的补发。普通日程是否产生提醒取决于该日程是否带有提醒数据。

## 11. 检查更新

打开“设置”→“桌面外观”，滚动到“应用更新”区域并点击“检查更新”。应用启动后也会自动检查一次；网络失败不会影响本地日历、天气或会议室功能。

如果发现新版本，主窗口右上角会出现蓝色下载图标，悬停可以查看版本号。点击图标会在默认浏览器中打开 HTTPS 安装包地址，下载完成后运行安装包升级；当前不是静默后台安装。安装前请先关闭正在运行的旧版本。

## 12. ICS 导入与导出

顶部工具按钮提供 ICS 导入和导出：

- 导入 ICS：选择外部日历文件并导入日程。
- 导出 ICS：将本地日历导出为标准 `.ics` 文件，便于备份或导入其他日历软件。

## 13. 常见问题

### 创建后看不到项目、记录或日程

确认在快速新增窗口点击了“创建”，而不是直接关闭窗口。创建成功后切换页面或重新打开页面即可刷新列表。

### 保存版本没有新增版本

只有正文内容发生变化时才会创建新版本。如果提示“内容未变化”，说明当前正文与上一个版本相同。

### 团队会议室为空或仍显示本地房间

检查“设置”→“团队连接”是否已显示“已登录”，服务端地址是否可访问，工作区 ID 是否正确。登录成功后重新打开快速新增或点击看板刷新。云端目录加载失败时，应用会保留最后一次成功的云端快照，不会把失败误显示成空目录。

### 在线预约冲突

冲突不会删除本地日程。查看提示中的房间、时间和预约人，换用其他会议室或调整时间；如果蓝色预约是自己之前创建的重复记录，可在看板双击后删除。

### 他人的预约如何加入我的日程

在会议室看板双击灰色预约，在详情窗口点击“添加到我的日程”。这只创建本地日程，不会再次提交云端预约。

### 天气与其他软件不同

先确认“今天”页面中的城市和定位是否正确，再比较数据来源和更新时间。cccalendar 使用 Open-Meteo 预报数据。

### 更新检查失败

确认电脑可以访问 OSS 公网地址，并在“设置”→“桌面外观”→“应用更新”中重新点击“检查更新”。更新检查失败不会影响本地日历、待办和记录使用。

## 14. 数据备份建议

重要数据建议定期使用 ICS 导出备份日程，并备份整个 `C:\Users\<用户名>\AppData\Local\cccalendar` 目录。迁移到另一台电脑前，先退出应用，再复制该目录；团队会议室预约保存在云端，不需要随本地目录迁移。备份目录可能包含本地连接配置和 AI 历史，请像保管个人数据一样妥善保护。彻底清除本地数据前请确认已完成备份。
